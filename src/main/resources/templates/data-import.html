Import data

Import a CATS JSON file using the cats-import-v1 format. You may import users, providers, courses, holidays, applications or any combination. Existing records are never silently overwritten; conflicts reject the entire import.

Account values are imported as provided, including roles, activation state, email addresses and BCrypt password hashes. Make sure the file is trusted, especially when importing administrator accounts. Importing does not automatically configure MFA for newly imported users.

Back up the database before importing. Maximum upload size: 500 KB. See docs/data-import.md for the schema and field requirements.
